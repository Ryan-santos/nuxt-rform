## 1. One field

A field works on its own, with no `RForm` around it — it just does not reach any
model.

```vue
<RText
    label="Name"
    placeholder="what people call you"
/>
```

## 2. A form

`RForm` is what provides the model. From here on, `name` is the key.

```vue
<template>
    <RForm v-model="data">
        <RText
            name="name"
            label="Name"
        />
        <RText
            name="email"
            label="E-mail"
        />
    </RForm>
</template>

<script setup lang="ts">
    import { ref } from "vue";

    const data = ref<Record<string, unknown>>({});
</script>
```

## 3. Types

`useRForm<T>()` does nothing at runtime: it only types `data`.

```ts
type Signup = {
    name?: string;
    email?: string;
};

const { data } = useRForm<Signup>();
```

## 4. Validation

Each field declares its own `rule`, and `RForm` runs them on submit.

```vue
<RForm
    v-model="data"
    @submit="send"
>
    <RText
        name="name"
        label="Name"
        required
        rule="required"
    />
    <RText
        name="email"
        label="E-mail"
        rule="email"
    />

    <button type="submit">Send</button>
</RForm>
```
