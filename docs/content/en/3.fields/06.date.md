`RDate`'s model changes **shape** with `mode`: a string in `single`, a tuple in
`range`, an array in `multiple`. And it is always ISO — the display format is a
different thing, and comes from the translation pack.

::callout{type="info"}
`formatIso` and the ISO branch of `parseIncoming` are deliberately **not**
localized: ISO is the model's format and is language-independent. Localizing it
would make the stored value change with the language on screen. What does change
with the locale is only the typing mask and the display, derived from
`rform.formats.date` — switch the language in the footer and watch the field
rewrite itself without the model changing.
::

## Icons

Each role is a key of the `icons` prop, and the value is the iconify name. A
util's roles nest under `Utils`, as in `ui`:
`:icons="{ Utils: { Error: { alert: 'lucide:circle-alert' } } }"`. Layers,
`defineFieldDefaults` and the alias are in
[Icons](/en/concepts/icones#per-component-or-per-tag).

| role                    | default                                           | where it shows                               |
| ----------------------- | ------------------------------------------------- | -------------------------------------------- |
| `calendar`              | `rform:calendar` → `fa6-regular:calendar`         | the button that opens the calendar           |
| `Utils.Calendar.prev`   | `rform:chevron-left` → `fa6-solid:chevron-left`   | moves the calendar view back                 |
| `Utils.Calendar.next`   | `rform:chevron-right` → `fa6-solid:chevron-right` | moves the calendar view forward              |
| `Utils.Loading.loading` | `rform:loading` → `eos-icons:loading`             | the field's spinner, with the `loading` prop |
| `Utils.Error.alert`     | `rform:alert` → `ooui:alert`                      | next to the error message                    |
