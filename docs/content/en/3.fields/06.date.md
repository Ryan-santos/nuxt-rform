`RDate`'s model changes **shape** with `mode`: a string in `single`, a tuple in
`range`, an array in `multiple`. And it is always ISO — the display format is a
different thing, and comes from the translation pack.

::callout{type="info"}
`formatIso` and the ISO branch of `parseIncoming` are deliberately **not**
localized: ISO is the model's format and is language-independent. Localizing it
would make the stored value change with the language on screen. What does change
with the locale is only the typing mask and the display, derived from
`rform.formats.date` — switch the language in the footer and watch the field
rewrite itself without the model changing.
::
