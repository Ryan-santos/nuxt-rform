`RSwitch` is the one exception to the role of `placeholder`: in the other
fields it is the floating label that rises when the field is filled; here it is
the text on the same line as the button.

## Icons

Each role is a key of the `icons` prop, and the value is the iconify name. A
util's roles nest under `Utils`, as in `ui`:
`:icons="{ Utils: { Error: { alert: 'lucide:circle-alert' } } }"`. Layers,
`defineFieldDefaults` and the alias are in
[Icons](/en/concepts/icones#per-component-or-per-tag).

| role                | default                               | where it shows                            |
| ------------------- | ------------------------------------- | ----------------------------------------- |
| `on`                | `rform:check` → `fa6-solid:check`     | in the indicator, when on                 |
| `off`               | `""` — no icon                        | in the indicator, when off                |
| `loading`           | `rform:loading` → `eos-icons:loading` | in the indicator, with the `loading` prop |
| `Utils.Error.alert` | `rform:alert` → `ooui:alert`          | next to the error message                 |

`""` leaves that state without an icon, and `""` on all three turns the
indicator off. There is no other prop for it: the boolean `icon` is gone.
