title: Switch
tag: RSwitch
description: Boolean. Here placeholder becomes the text next to the button, not a floating label.
---

`RSwitch` is the one exception to the role of `placeholder`: in the other
fields it is the floating label that rises when the field is filled; here it is
the text on the same line as the button.

::demo{src="Switch/label-placeholder" title="both, together and apart"}

::

## icon

`true` uses the default icons — the `rform:check` alias when on and `rform:loading`
while loading. The object swaps each state for an icon of yours, by its iconify
name.
