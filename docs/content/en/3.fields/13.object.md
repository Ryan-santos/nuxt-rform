The children's `name`s become keys inside `RObject`'s key. It provides its own
model to the children, but does **not** override the form root — a rule down
there still sees the whole form, not just the branch.

## A nested rule sees the whole form

The `form` of a validation comes from `defineFormRoot`, provided **only** by
`RForm` — `RArray` and `RObject` do not override it.

## default

::demo{src="Object/default" title="default"}
An object's `default` is **cloned** per instance: `useField` calls
`structuredClone` precisely so a child cannot write into the object the
component declared at module scope.
