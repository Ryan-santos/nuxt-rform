title: Radio
tag: RRadio
description: A single choice among options that are always visible. The same three options formats as Select.
---

`RRadio` is `RSelect` without the panel: every option stays on screen, and only
one can be checked. What reaches the model is the option's **value**, never the
object — there is no `modelFull` here.

The arrow keys move through the group, because every input gets the same native
`name`.

## options

The three formats and `pick` are the same as in
[Select](/en/fields/select#options), with the same rules.

### Primitive array

The value and the label are the item itself.

::demo{src="Radio/primitivo" title="primitive array"}
::

### Object `{ key: label }`

The key goes to the model; the object's value becomes the label.

::demo{src="Radio/objeto" title="object"}
::

### Array of objects

`pick` says which fields of the item become the value and the label, defaulting
to `{ value: "id", label: "name" }`. Overriding one of the two keys keeps the
other.

::demo{src="Radio/pick" title="pick, with a default"}
`:default="2"` starts checked — and it is the `id`, not the object, that shows up
in the model.
::

The model is typed by `pick`: with a numeric `id`, `@update:model-value`
receives `number | null`. Write `pick` **inline**, for the same reason as in
[Select](/en/fields/select#typing).

## Slot

The default slot receives `{ option, checked }` and replaces each option's
label. `option.original` is the raw item, typed by `options`.

::demo{src="Radio/slot" title="the label with the price next to it"}
::

## States

`disabled` reaches every input in the group, so no option takes a click or
focus.
