`RNumber`'s model is `number | null` — and that type does not come from
`default`, as it does in the other fields: the component passes `D` as the third
parameter of `Element<typeof defaults, "number", number | null>`, overriding what
would come out on its own.

## The basics

The `default` the component declares is `0`, so the field is already in the
model.

## Icons

Each role is a key of the `icons` prop, and the value is the iconify name. A
util's roles nest under `Utils`, as in `ui`:
`:icons="{ Utils: { Error: { alert: 'lucide:circle-alert' } } }"`. Layers,
`defineFieldDefaults` and the alias are in
[Icons](/en/concepts/icones#per-component-or-per-tag).

| role                    | default                               | where it shows                               |
| ----------------------- | ------------------------------------- | -------------------------------------------- |
| `decrement`             | `rform:minus` → `fa6-solid:minus`     | the decrement button, on the left            |
| `increment`             | `rform:plus` → `fa6-solid:plus`       | the increment button, on the right           |
| `Utils.Loading.loading` | `rform:loading` → `eos-icons:loading` | the field's spinner, with the `loading` prop |
| `Utils.Error.alert`     | `rform:alert` → `ooui:alert`          | next to the error message                    |
