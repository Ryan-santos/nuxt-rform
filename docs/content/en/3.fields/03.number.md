`RNumber`'s model is `number | null` — and that type does not come from
`default`, as it does in the other fields: the component passes `D` as the third
parameter of `Element<typeof defaults, "number", number | null>`, overriding what
would come out on its own.

## The basics

The `default` the component declares is `0`, so the field is already in the
model.

with a number in the model they become `z.number().min()` / `.max()`.
