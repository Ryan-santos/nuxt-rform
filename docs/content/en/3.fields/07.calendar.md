`RCalendar` accepts the same `mode`, `time` and `disable` as `RDate` — the
difference is that it does not open in a popover, it is always on screen.

::callout{type="tip"}
`Calendar` exists as a **field** and as a **util** (`RUtilsCalendar`, the panel
`RDate` mounts inside the popover). They do not collide: the translation prefix
is per scope, so one lives under `rform.fields.calendar.*` and the other under
`rform.utils.calendar.*`.
::

## Icons

The field draws no icon of its own; the ones in the table belong to the utils it
renders. Each role is a key of the `icons` prop, and the value is the iconify
name. A util's roles nest under `Utils`, as in `ui`:
`:icons="{ Utils: { Error: { alert: 'lucide:circle-alert' } } }"`. Layers,
`defineFieldDefaults` and the alias are in
[Icons](/en/concepts/icones#per-component-or-per-tag).

| role                  | default                                           | where it shows                  |
| --------------------- | ------------------------------------------------- | ------------------------------- |
| `Utils.Calendar.prev` | `rform:chevron-left` → `fa6-solid:chevron-left`   | moves the calendar view back    |
| `Utils.Calendar.next` | `rform:chevron-right` → `fa6-solid:chevron-right` | moves the calendar view forward |
| `Utils.Error.alert`   | `rform:alert` → `ooui:alert`                      | next to the error message       |
