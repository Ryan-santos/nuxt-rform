Paste, backspace and arrow navigation work as in a single field — because the
model **is** a single field: the whole string, not an array of characters.

the field would start comparing `"numeric"` with `"rform.fields.pin.numeric"`.

## autocomplete

`one-time-code` is the token that makes Chrome and Safari offer the code that
just arrived by SMS. It goes on the **first** box and only there — that is where
the autofiller looks, and the other N-1 get no attribute at all. You write the
prop once, on the field:

::demo{src="Pin/autocomplete" title="one-time-code"}
On a device receiving the SMS, the keyboard offers the code above the first box;
accepting it spreads the digits across the others.
::

The rest of the prop — the tokens it takes, the six fields that have it and why
it is a prop instead of an attribute — is in
[Text](/en/fields/text#autocomplete).
