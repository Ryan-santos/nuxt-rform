## mask on a textarea

This is the field that justifies the module's own directive. `v-maska` does

```js
const a = e instanceof HTMLInputElement ? e : e.querySelector("input");
if (a == null || a?.type === "file") return;
```

— and a `<textarea>` falls outside both branches, so it is never bound. maska's
`MaskInput`, however, only uses `value`, `selectionStart`, `setSelectionRange`,
`addEventListener` and `dispatchEvent`, all of which a textarea has: only the
guard excludes it. The module's `vMask` instantiates `MaskInput` directly on the
element, input **or** textarea.
