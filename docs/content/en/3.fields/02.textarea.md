resolution of `mask` and `rule`. What it adds is `rows`, the initial height.

## mask on a textarea

This is the field that justifies the module's own directive. `v-maska` does

```js
const a = e instanceof HTMLInputElement ? e : e.querySelector("input");
if (a == null || a?.type === "file") return;
```

— and a `<textarea>` falls outside both branches, so it is never bound. maska's
`MaskInput`, however, only uses `value`, `selectionStart`, `setSelectionRange`,
`addEventListener` and `dispatchEvent`, all of which a textarea has: only the
guard excludes it. The module's `vMask` instantiates `MaskInput` directly on the
element, input **or** textarea.

## Icons

The field draws no icon of its own; the ones in the table belong to the utils it
renders. Each role is a key of the `icons` prop, and the value is the iconify
name. A util's roles nest under `Utils`, as in `ui`:
`:icons="{ Utils: { Error: { alert: 'lucide:circle-alert' } } }"`. Layers,
`defineFieldDefaults` and the alias are in
[Icons](/en/concepts/icones#per-component-or-per-tag).

| role                    | default                               | where it shows                               |
| ----------------------- | ------------------------------------- | -------------------------------------------- |
| `Utils.Loading.loading` | `rform:loading` → `eos-icons:loading` | the field's spinner, with the `loading` prop |
| `Utils.Error.alert`     | `rform:alert` → `ooui:alert`          | next to the error message                    |
