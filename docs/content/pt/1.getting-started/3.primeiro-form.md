## 1. Um campo

Um campo funciona sozinho, sem `RForm` em volta — ele só não entra em model
nenhum.

```vue
<RText
    label="Nome"
    placeholder="como te chamam"
/>
```

## 2. Um formulário

O `RForm` é quem provê o model. A partir daqui, `name` é a chave.

```vue
<template>
    <RForm v-model="data">
        <RText
            name="nome"
            label="Nome"
        />
        <RText
            name="email"
            label="E-mail"
        />
    </RForm>
</template>

<script setup lang="ts">
    import { ref } from "vue";

    const data = ref<Record<string, unknown>>({});
</script>
```

## 3. Tipos

`useRForm<T>()` não faz nada em runtime: só tipa o `data`.

```ts
type Cadastro = {
    nome?: string;
    email?: string;
};

const { data } = useRForm<Cadastro>();
```

## 4. Validação

Cada campo declara a própria `rule`, e o `RForm` as roda no submit.

```vue
<RForm
    v-model="data"
    @submit="enviar"
>
    <RText
        name="nome"
        label="Nome"
        required
        rule="required"
    />
    <RText
        name="email"
        label="E-mail"
        rule="email"
    />

    <button type="submit">Enviar</button>
</RForm>
```
