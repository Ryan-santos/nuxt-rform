`RSwitch` é a única exceção ao papel do `placeholder`: nos outros campos ele é
o rótulo flutuante que sobe quando o campo é preenchido; aqui é o texto na mesma
linha do botão.

## Ícones

Cada papel é uma chave da prop `icons`, e o valor é o nome do iconify. Os papéis
de um util ficam aninhados sob `Utils`, como no `ui`:
`:icons="{ Utils: { Error: { alert: 'lucide:circle-alert' } } }"`. Camadas,
`defineFieldDefaults` e o alias estão em
[Ícones](/pt/concepts/icones#por-componente-ou-por-tag).

| papel               | padrão                                | onde aparece                       |
| ------------------- | ------------------------------------- | ---------------------------------- |
| `on`                | `rform:check` → `fa6-solid:check`     | no indicador, ligado               |
| `off`               | `""` — sem ícone                      | no indicador, desligado            |
| `loading`           | `rform:loading` → `eos-icons:loading` | no indicador, com a prop `loading` |
| `Utils.Error.alert` | `rform:alert` → `ooui:alert`          | ao lado da mensagem de erro        |

`""` deixa aquele estado sem ícone, e `""` nos três desliga o indicador. Não há
outra prop para isso: a `icon` booleana saiu.
