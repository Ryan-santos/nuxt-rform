`RSwitch` é a única exceção ao papel do `placeholder`: nos outros campos ele é
o rótulo flutuante que sobe quando o campo é preenchido; aqui é o texto na mesma
linha do botão.

## icon

`true` usa os ícones padrão — os aliases `rform:check` quando ligado e
`rform:loading` enquanto carrega. O objeto troca cada estado por um ícone seu, pelo
nome do iconify.
