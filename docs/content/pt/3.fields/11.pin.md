Cola, backspace e navegação com setas funcionam como num campo só — porque o
model **é** um campo só: a string inteira, não um array de caracteres.

## type

::demo{src="Pin/type" title="numeric e alphanumeric"}
`numeric` aceita só dígitos; `alphanumeric` aceita letras e mostra em maiúsculas.
::

::callout{type="warn"}
`type` fica **fora** de `defaults.text`, ao lado do `pick` do Select. Dentro, o auto-prefixo o transformaria numa chave de tradução — e o
campo passaria a comparar `"numeric"` com `"rform.fields.pin.numeric"`.
::

## autocomplete

`one-time-code` é o token que faz o Chrome e o Safari oferecerem o código que
acabou de chegar por SMS. Ele vai na **primeira** caixa e só nela — é ali que o
preenchedor procura, e as outras N-1 ficam sem atributo nenhum. Você escreve a
prop uma vez, no campo:

::demo{src="Pin/autocomplete" title="one-time-code"}
Num aparelho com o SMS chegando, o teclado oferece o código sobre a primeira
caixa; aceitar espalha os dígitos pelas outras.
::

O resto da prop — os tokens que ela aceita, os seis campos que a têm e o porquê
de ser prop em vez de atributo — está em
[Text](/pt/fields/text#autocomplete).
