## mask num textarea

Este é o campo que justifica a diretiva própria. A `v-maska` faz

```js
const a = e instanceof HTMLInputElement ? e : e.querySelector("input");
if (a == null || a?.type === "file") return;
```

— e um `<textarea>` cai fora dos dois ramos, então nunca é bindado. O
`MaskInput` do maska, porém, só usa `value`, `selectionStart`,
`setSelectionRange`, `addEventListener` e `dispatchEvent`, que um textarea tem:
só o guard exclui. O `vMask` do módulo instancia o `MaskInput` direto no
elemento, input **ou** textarea.
