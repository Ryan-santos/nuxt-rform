Os `name` dos filhos viram chaves dentro da chave do `RObject`. Ele provê o
próprio model para os filhos, mas **não** sobrescreve o form root — uma rule lá
dentro continua enxergando o formulário inteiro, não só o galho.

## A rule aninhada enxerga o form inteiro

O `form` da validação vem de `defineFormRoot`, provido **só** pelo `RForm` —
`RArray` e `RObject` não o sobrescrevem.

## default

::demo{src="Object/default" title="default"}
O `default` de um objeto é **clonado** por instância: o `useField` faz
`structuredClone` justamente para um filho não escrever no objeto que o
componente declarou em escopo de módulo.
