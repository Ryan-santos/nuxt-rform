::callout{type="tip"}
O `border-white` dos marcadores do picker é literal **por desenho**: o marcador
precisa contrastar com uma cor arbitrária, então não é um token de tema que
alguém esqueceu de trocar. `text-white` seria drift; `border-white` aqui não é.
