---

`RCalendar` aceita os mesmos `mode`, `time` e `disable` do `RDate` — a
diferença é que ele não abre em popover, está sempre na tela.

::callout{type="tip"}
`Calendar` existe como **campo** e como **util** (`RUtilsCalendar`, o painel que
o `RDate` monta dentro do popover). Não colidem: o prefixo de tradução é por
escopo, então um vive em `rform.fields.calendar.*` e o outro em
`rform.utils.calendar.*`.
::

## Ícones

O campo não desenha ícone próprio; os da tabela são dos utils que ele renderiza.
Cada papel é uma chave da prop `icons`, e o valor é o nome do iconify. Os papéis
de um util ficam aninhados sob `Utils`, como no `ui`:
`:icons="{ Utils: { Error: { alert: 'lucide:circle-alert' } } }"`. Camadas,
`defineFieldDefaults` e o alias estão em
[Ícones](/pt/concepts/icones#por-componente-ou-por-tag).

| papel                 | padrão                                            | onde aparece                 |
| --------------------- | ------------------------------------------------- | ---------------------------- |
| `Utils.Calendar.prev` | `rform:chevron-left` → `fa6-solid:chevron-left`   | volta a visão do calendário  |
| `Utils.Calendar.next` | `rform:chevron-right` → `fa6-solid:chevron-right` | avança a visão do calendário |
| `Utils.Error.alert`   | `rform:alert` → `ooui:alert`                      | ao lado da mensagem de erro  |
