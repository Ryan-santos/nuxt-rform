`RRadio` é o `RSelect` sem painel: as opções ficam todas na tela, e só uma pode
estar marcada. O que vai pro model é o **valor** da opção, nunca o objeto — não
há `modelFull` aqui.

As setas do teclado andam pelo grupo, porque todo input recebe o mesmo `name`
nativo.

## options

Os três formatos e o `pick` são os mesmos do
[Select](/pt/fields/select#options), com as mesmas regras.

### Array primitivo

O valor e o rótulo são o próprio item.

::demo{src="Radio/primitivo" title="array primitivo"}
::

### Objeto `{ chave: rótulo }`

A chave vai pro model; o valor do objeto vira o rótulo.

::demo{src="Radio/objeto" title="objeto"}
::

### Array de objetos

`pick` diz quais campos do item viram o valor e o rótulo, com default
`{ value: "id", label: "name" }`. Sobrescrever uma das duas chaves conserva a
outra.

::demo{src="Radio/pick" title="pick, com default"}
`:default="2"` já sai marcado — e é o `id`, não o objeto, que aparece no model.
::

O model é tipado pelo `pick`: com `id` numérico, `@update:model-value` recebe
`number | null`. Escreva o `pick` **inline**, pelo mesmo motivo do
[Select](/pt/fields/select#tipagem).

## Slot

O slot default recebe `{ option, checked }` e substitui o rótulo de cada opção.
`option.original` é o item cru, tipado pelo `options`.

::demo{src="Radio/slot" title="o rótulo com o preço ao lado"}
::
