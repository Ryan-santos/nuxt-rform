`RCheckbox` tem dois modos, e quem decide é a presença de `options`:

| `options` | o model                      | o texto ao lado                 |
| --------- | ---------------------------- | ------------------------------- |
| ausente   | `boolean`                    | o `placeholder`, como no Switch |
| presente  | a lista dos `value` marcados | o rótulo de cada opção          |

## Booleano

Sem `options`, o `placeholder` é o texto na mesma linha da caixa — o mesmo papel
que ele tem no [Switch](/pt/fields/switch). `label` fica acima, como nos outros
campos.

::demo{src="Checkbox/booleano" title="placeholder ao lado, label acima"}
::

## options

Com `options`, cada opção é uma caixa, e o model guarda os valores marcados na
ordem em que foram marcados. Os três formatos e o `pick` são os mesmos do
[Select](/pt/fields/select#options).

O model começa `[]`, sem tocar no campo: o `false` do modo booleano nunca chega
ao form.

::demo{src="Checkbox/options" title="lista"}
::

### Array de objetos e slot

`pick` escolhe o valor e o rótulo. O slot default recebe `{ option, checked }`,
com `option.original` sendo o item cru, e substitui o rótulo de cada caixa.

::demo{src="Checkbox/pick" title="pick e slot"}
::

## Estados

A rule `required` trata a caixa desmarcada (`false`) e a lista vazia (`[]`) como
vazias, então ela serve aos dois modos.

::demo{src="Checkbox/estados" title="required nos dois modos, disabled e error"}
::

## Ícones

Cada papel é uma chave da prop `icons`, e o valor é o nome do iconify. Os papéis
de um util ficam aninhados sob `Utils`, como no `ui`:
`:icons="{ Utils: { Error: { alert: 'lucide:circle-alert' } } }"`. Camadas,
`defineFieldDefaults` e o alias estão em
[Ícones](/pt/concepts/icones#por-componente-ou-por-tag).

| papel               | padrão                            | onde aparece                |
| ------------------- | --------------------------------- | --------------------------- |
| `check`             | `rform:check` → `fa6-solid:check` | dentro da caixa marcada     |
| `Utils.Error.alert` | `rform:alert` → `ooui:alert`      | ao lado da mensagem de erro |
