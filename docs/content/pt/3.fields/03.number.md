O model de `RNumber` é `number | null` — e esse tipo não sai do `default`, como
nos outros campos: o componente passa `D` como terceiro parâmetro de
`Element<typeof defaults, "number", number | null>`, sobrescrevendo o que sairia
sozinho.

## O básico

O `default` que o componente declara é `0`, então o campo já nasce no model.
