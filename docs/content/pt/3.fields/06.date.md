O model de `RDate` muda de **forma** conforme o `mode`: string em `single`,
tupla em `range`, array em `multiple`. E é sempre ISO — o formato de exibição é
outra coisa, e vem do pack de tradução.

::callout{type="info"}
`formatIso` e o ramo ISO de `parseIncoming` **não** são localizados de
propósito: ISO é o formato do model e é independente de idioma. Localizá-lo
faria o valor gravado mudar com o idioma da tela. O que muda com o locale é só a
máscara de digitação e a exibição, derivadas de `rform.formats.date` — troque o
idioma no rodapé e veja o campo se reescrever sem o model mudar.
::
