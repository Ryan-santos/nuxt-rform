O model de `RDate` muda de **forma** conforme o `mode`: string em `single`,
tupla em `range`, array em `multiple`. E é sempre ISO — o formato de exibição é
outra coisa, e vem do pack de tradução.

::callout{type="info"}
`formatIso` e o ramo ISO de `parseIncoming` **não** são localizados de
propósito: ISO é o formato do model e é independente de idioma. Localizá-lo
faria o valor gravado mudar com o idioma da tela. O que muda com o locale é só a
máscara de digitação e a exibição, derivadas de `rform.formats.date` — troque o
idioma no rodapé e veja o campo se reescrever sem o model mudar.
::

## Ícones

Cada papel é uma chave da prop `icons`, e o valor é o nome do iconify. Os papéis
de um util ficam aninhados sob `Utils`, como no `ui`:
`:icons="{ Utils: { Error: { alert: 'lucide:circle-alert' } } }"`. Camadas,
`defineFieldDefaults` e o alias estão em
[Ícones](/pt/concepts/icones#por-componente-ou-por-tag).

| papel                   | padrão                                            | onde aparece                             |
| ----------------------- | ------------------------------------------------- | ---------------------------------------- |
| `calendar`              | `rform:calendar` → `fa6-regular:calendar`         | o botão que abre o calendário            |
| `Utils.Calendar.prev`   | `rform:chevron-left` → `fa6-solid:chevron-left`   | volta a visão do calendário              |
| `Utils.Calendar.next`   | `rform:chevron-right` → `fa6-solid:chevron-right` | avança a visão do calendário             |
| `Utils.Loading.loading` | `rform:loading` → `eos-icons:loading`             | o spinner do campo, com a prop `loading` |
| `Utils.Error.alert`     | `rform:alert` → `ooui:alert`                      | ao lado da mensagem de erro              |
